# 小红书评论 Topic Room Demo

这是一个零依赖、纯前端的手机端交互 Demo。

## 发布方式

- 网站入口：`index.html`
- 静态素材：`sydney-rental-cover.png`
- 不需要后端、数据库、环境变量或真实 AI
- 不需要执行 `npm install` 或任何构建命令
- 发布时将当前文件夹作为静态网站根目录即可

## 本地预览

可以直接打开 `index.html`，或者使用任意静态文件服务器打开当前目录。

## 重要要求

请保留 `index.html` 和 `sydney-rental-cover.png` 在仓库根目录，不要重写页面，不要删除交互脚本，也不要把它转换成其他框架。
